# SAMVAD-AI-CHATBOT

A modern, serverless AI chatbot application designed for fast deployment.

## Features

- Real-time conversational interface built with clean HTML and JavaScript.
- Serverless backend API routes optimized for cloud hosting.
- Pre-configured deployment settings via Vercel.

## About the Project

Samvaad AI Chatbot is designed with a profound social mission: to bridge the gap between citizens and complex government welfare systems. Navigating official portals, eligibility criteria, and bureaucratic documentation can be overwhelming for many people. This application leverages AI to instantly analyze user requirements and match them with the perfect government schemes, subsidies, and financial assistance programs they are eligible for.
